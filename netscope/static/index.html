Network topology

Containers can only reach each other by name when they share a network (Podman's aardvark-dns only answers for containers on the same network). Internal networks (podman network create --internal) have no route to the outside world.

Connectivity matrix

For every running container, NetScope starts a short-lived probe container inside that container's network namespace (--network container:<name>) and tries to reach every other container's exposed ports. Results are compared with what the network design says should happen.
